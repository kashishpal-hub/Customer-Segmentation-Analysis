# Customer Segmentation Analysis – Internship Task 2

This project was completed as part of my Data Analytics Internship at Oasis Infobyte.

## Project Overview

Performed customer data analysis and segmentation using Python, exploratory data analysis, visualization, and K-Means clustering to identify meaningful customer groups.

## Key Analysis

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Customer data visualization
* Feature analysis
* K-Means clustering
* Customer segmentation
* Cluster visualization
* Business insights generation

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Files

* `Customer_Segmentation_Analysis.ipynb` – Complete analysis and clustering
* `Customer_Segmentation_Dataset.csv` – Dataset used for the project

## Key Learning

This project provided hands-on experience in data preprocessing, exploratory analysis, visualization, and applying machine learning techniques such as K-Means clustering to real-world customer data.
